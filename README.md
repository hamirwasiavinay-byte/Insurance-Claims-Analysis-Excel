# Insurance-Claims-Analysis-Excel
Interactive Excel dashboard analyzing health insurance claim trends and customer risk profiles.

## Tools Used
-Microsoft Excel
-Pivot Tables
-Pivot Charts
-Slicers
-Excel Formulas

## Key Features
-Claim severity analysis
-Age-wise claim trends
-Smoker vs non-smoker comparison
-BMI risk analysis
-Region-wise analysis

## Key Insights
-Smokers showed significantly higher average claim amounts.
-Obese customers had higher insurance costs.
-Middle-aged customers contributed the highest claims.
